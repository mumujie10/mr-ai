# 文档索引

这里是 MireAI 桌面客户端的**工程文档**。面向新加入的成员：不需要读完，按你要做的事挑一条路径走。

关于文件名：本目录下的文档用中文文件名，标题与正文都中文。只有这份索引叫 `README.md`——GitHub 的目录页会自动渲染它，名字必须保留。

## 团队规范分类

[团队规范/README](./团队规范/README.md) 是总览，分类如下：

- **代码与命名** — 目录归属、前后端命名、必须同步的镜像清单
- **分支提交与评审** — 本仓是 `main` 上开发、按 tag 发版
- **文档与界面文案** — 谁改谁更新、变更记录、i18n 双语、品牌口径
- **安全与隐私红线** — 密钥、日志、外发、系统权限

## 与 AGENTS.md 的分工

仓库根的 [AGENTS.md](../AGENTS.md) 是给 AI 协作 agent 的执行约定（建立上下文、影响面验证、交付口径）。这里的文档是给**人**读的项目事实与团队规范。两者冲突时，以代码与 AGENTS.md 的项目级禁令（例如"严禁主动提交"）为准。

## 历史设计文档

[plans/](./plans/) 与 [design/](./design/) 是按日期沉淀的实施计划与设计方案，**是历史档案，不是当前事实的来源**。它们记录了当时为什么这样做（例如 `mission-workbench-plan.md`、`2026-09-23-skills-mcp-migration.md`），但实现已经往前走，具体行为以代码为准。想知道现在是什么样，读上面那几篇。
